# thzdaq-mcp

`thzdaq mcp`: the bench's tools for agents (Claude Code, Codex) over MCP stdio. A client of
the daemon through `thzdaq-api`, like the GUI and the command line: tools are operations of
the contract's catalog, every call carries the origin `mcp:<agent>`, and what an agent
changes waits for a person in the ThzDAQ window. Install it as `thzdaq[mcp]`; see
[docs/daemon.md](https://github.com/yarvod/ThzDAQ/blob/master/docs/daemon.md), «MCP-сервер».
