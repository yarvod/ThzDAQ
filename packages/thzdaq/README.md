# thzdaq

What a user installs from PyPI: the `thzdaq` command and the client library for scripts
(`from thzdaq import connect`), light, without drivers or numpy. Extras: `analysis`
(analysis functions for scripts), `daemon` (the bench daemon with drivers), `gui`, `mcp`
(`thzdaq mcp`, the bench's tools for Claude Code and Codex), `all`. The `jupyter` extra
comes with its package.
